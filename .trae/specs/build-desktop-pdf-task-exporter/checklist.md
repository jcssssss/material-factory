- [x] 桌面应用可启动并显示基础工作台界面
- [x] 一个任务被明确建模为一个商品处理单元
- [x] 用户可为一个任务选择单个 PDF、多个 PDF 或一个包含多个 PDF 的文件夹
- [x] 文件夹内没有 PDF 时系统会阻止任务开始执行
- [x] 用户可配置前 N 页导出规则
- [x] 用户可配置自定义页码或页码范围导出规则
- [x] 当前 N 页与自定义页码可同时配置，并会合并去重后执行
- [x] 系统会阻止非法页码表达式进入执行流程
- [x] 系统会阻止非 PDF 输入进入执行流程
- [x] 多个任务会按顺序自动执行，无需手动逐个启动
- [x] 单页失败时会记录错误并继续下一页
- [x] 单个 PDF 失败时会记录错误并继续同任务其他 PDF
- [x] 单任务失败时会记录错误并继续下一任务
- [x] 导出结果为固定 3:4 竖版 JPG
- [x] 导出结果满足质量 100% 与目标 300 DPI 规格
- [x] 页面比例不匹配时会采用等比缩放、居中放置和补边，而不是裁切主体内容
- [x] 输出文件按任务目录组织；多 PDF 场景下按 PDF 子目录隔离
- [x] 图片文件命名可稳定区分 PDF 来源与页码
- [x] 界面可显示当前任务、当前 PDF、当前页进度与失败统计
- [x] 系统会保存最近任务、任务输入参数、输出目录、执行状态与错误日志
- [x] 用户可查看历史任务结果、输出目录和执行日志
- [x] 关闭应用后再次打开时，历史记录仍可查看，但未完成队列不会自动恢复
- [x] 首版不要求支持 Word、云端同步、模板编辑器、多尺寸导出或并发任务执行
