# PRD Draft

## 背景与需求

1. **高效制作商品图片与笔记图片** — 输入一个或多个资料文件（支持 PDF、Word，后续可扩展更多格式），自动生成可直接用于商品详情页和小红书笔记制作的高清图片素材。还想去资料中的水印、页眉、页脚，需要的时候添加自己的水印、页眉、页脚。
2. **减少重复劳动** — 制作资料图片太慢，想减少重复劳动、降低人工成本。
3. **现状** — 已经买了一段时间了，有成交，每天投入 8-10 个小时左右，发现作图比较浪费时间而且是重复性的工作。
4. **目标用户** — 一个可以自己和老婆使用的自动化做图片素材的工具。
5. **最终目的** - 将输入的资料转换成符合我要求图片，尽量输入完资料后，全程自动化，减少人工干预。
## 痛点与自动化目标

我现在想把一些重复的工作进行整理，通过 AI Coding 开发一些工具进行自动化，减少重复劳动，提交效率。现在我能想到的重复且比较费事的工作是：

1. 做商品图片、做笔记图片
2. 多账号每天分别需要发布 10 篇笔记
3. 经常上架新商品、更新旧商品
4. 另外我还需要一个通过大量爆款商品数据分析进行的选品工具和通过大量爆款笔记分析进行模仿笔记的笔记模板工具。

## 核心理念

最后很重要！下面是我梳理我小红书虚拟资料整个项目理解和整套操作流程，这个项目最重要的只有两点。

首先是**选品**，其次是**笔记**！

操作流程是，先选品，选择不侵权且好卖的赛道和品，我现在卖的是各个阶段考试的历年真题及答案解析，我暂时有品，所以现在不考虑选品的问题，但是后续的话我需要做一个数据分析的工具，通过数据分析来选品，模仿包块笔记。

## 完整操作流程

选完品后，开始找货源，各各平台买或一些网站保存到百度网盘或下载到本地电脑。

### 资料整理

接下来是比较费时间的重复劳动，这也是我这次想要做的工具。打开网盘或本地资料检查：

- 若有水印、页眉、页脚则通过 PDFgear 工具去掉水印、页眉、页脚
- 若 PDFgear 无法去除或 PDF 资料有密码无权限编辑修改，则上传到夸克网盘中，通过编辑中的涂改液涂掉水印、页眉、页脚
- 然后重新保存到本地电脑，再上传到百度网盘

### 截图制作

接着打开百度网盘中的资料预览，通过微信截图功能固定或随机截图几页资料，截图该资料在百度网盘中的列表（即有可能一份资料包有多个文件 pdf、word），目的为了让消费者看到我有哪些资料及部分预览。

截图后，将截图放到工具"稿定设计"的画板（3:4 1424 × 1656）中：

- 通过缩放截图将截图中的内容完整放在画板中
- 短边为资料预览的话则进行居中处理
- 短边为资料列表的话，将短边靠左长边撑满画板
- 一张一张的做

### 主图制作

然后做主图，主图也是使用稿定设计，在画板（3:4 1424×1656 或 1:1 1440×1440）中：

- 添加一个觉得不错的背景
- 主图一般放置几行文字（例如标题、年份、新版、历年真题+复习资料）等商品简介
- 设置文字大小、粗细、颜色、位置、文字背景颜色等文字样式
- 以及三张缩小且叠放阴影的资料截图（让消费者看到主图里的资料、证明我有资料）

### 图片排序与用途

接着添加文字，设置文字大小、粗细、颜色、位置、文字背景颜色等文字样式，让主图放在第一位，列表放在预览图的后边。

其中：

- **主图** — 用作商品主图和发布该资料第一次发布的笔记主图
- **资料内容部分预览图** — 作为商品详情图和第一次发布笔记除主图外的其他图片
- **资料列表图** — 作为商品详情图

### 上架与发布

图片做完之后先上架商品，商品上架完成后发布笔记。

笔记我会经常发，同一个资料也会发三遍左右：

1. **第一遍笔记** — 图片第一张用的是商品主图，第二张之后资料部分预览图挑几张
2. **第二遍笔记** — 图片我一般会发全部的资料部分预览图
3. **第三遍笔记** — 开始使用仿打印实拍图（详见下方流程）

### 仿打印实拍图制作

第三遍的笔记图片开始，我会：

1. 先用手机拿一打 A4 纸用夹子夹上，或者用一张 A4 纸，放到桌子、沙发等多场景背景下垂直拍照
2. A4 纸一般大概在照片的中间，A4 纸占比整张照片的 90% 以上
3. 然后把手机拍进行处理，处理成 3:4 的尺寸调调亮度什么的
4. 然后把手机拍好的照片传到电脑上，使用电脑上的 photopea 这个类似 photoshop 的工具进行背景和资料的整合
   - 即打开拍好的背景，打开资料的预览截图，将资料截图复制到背景中
   - 然后设置资料为正片叠底，这时资料截图就变成透明的了
   - 然后将透明的资料调整位置和大小等，使资料贴合 A4 纸，让资料看起来像是打印的
   - 这样就做出来一个资料打印版的实拍图，导出为质量 100% 的 jpg
5. 就这样一张资料一张资料的做实拍打印图
6. 然后将实拍打印图用作第三遍及以后的笔记发布图片

## 流程总结

总结一下这个项目的整体流程：

> **选品** → **整理资料** → **做商品图** → **上架商品** → **做笔记图** → **发布笔记**
