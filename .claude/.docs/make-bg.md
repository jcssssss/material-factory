 ---
  阶段一：准备背景模板

  入口：左侧导航栏 → "背景模板"页（/backgrounds）

  1. 上传背景照片：点击"上传"按钮，从本地选择一张手机拍的照片（J
  PG/PNG）。这张照片就是你拿手机对着 A4
  纸在桌子/沙发上拍的实拍图。
  2. 标定 A4 纸四角：上传成功后自动跳转到标定页（/calibrate/{tem
  plateId}）。页面显示你上传的背景照片，上面有一个红色虚线四边形
  ，四个角点标注 ①②③④。
  3. 拖拽角点：用鼠标把四个角点分别拖到照片中 A4
  纸的四个角上。这一步的作用是告诉系统"背景照片中，A4
  纸在这里"。
  4. 保存标定：点击保存，四个角点的归一化坐标存入 SQLite。

  ▎ 只有已标定的背景模板才会在后续合成中被使用。可以上传多个背景
  ▎ （不同场景、不同角度），合成时会随机轮流使用。

  ---
  阶段二：创建任务时启用合成

  入口：工作台（/）

  1. 照常创建 PDF
  转图任务（选文件/文件夹、设页码规则、选输出目录）。
  2. 勾选「图片合成（仿打印效果）」复选框。
  3. 如果没有任何已标定的背景模板，系统会弹窗提示先去上传标定。
  4. 点击"加入队列" → "启动队列"。

  ---
  阶段三：自动合成

  执行时机：所有 PDF 页都转成 JPG 后，自动触发。

  1. 收集素材：扫描任务输出目录下的所有 JPG 文件（刚生成的 PDF
  页转图）。
  2. 随机匹配背景：从已标定的背景模板中随机抽取，素材数超过模板
  数时会循环复用。
  3. 逐张合成（compositor.ts → Rust warp_to_a4）：
    - Rust 端用 DLT
  算法计算单应性矩阵，把资料图片透视变形到背景中 A4
  纸的四个角，返回 PNG
    - 前端 Canvas 把背景照片缩放居中，再把 warp 后的资料图片用
  multiply（正片叠底） 混合模式叠上去——白色纸张区域透过背景，黑
  色文字加深，形成"打印在纸上"的视觉效果
    - 嵌入 300 DPI 元数据，输出 1242×1656 JPG
  4. 输出：生成的文件保存在 {任务输出目录}/仿打印/001.jpg, 
  002.jpg ...

  ---
  一句话总结：上传实拍背景 → 标定 A4 纸位置 → 任务勾选合成选项 →
  PDF 转图完成后自动把所有 JPG 跟背景 multiply
  合成，输出仿打印效果的实拍图。
